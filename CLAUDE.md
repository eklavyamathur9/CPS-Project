# CLAUDE.md

This file provides guidance for working with the Acoustic Side-Channel
Simulator codebase.

## Project Overview

A software-based simulation of an acoustic side-channel attack on a
mechanical keyboard. Each key has a custom frequency signature; the system
identifies and reconstructs keystrokes from those frequencies.

**Important**: This is a *software simulation/prototype*. There is NO
microphone, no audio recording hardware, and no real-world acoustic capture.
All frequencies are predefined constants. Do not describe the project as
capturing real acoustic signals.

## Running the Application

```bash
# From the project root
python3 src/acoustic_side_channel.py
```

Requires: Python 3, tkinter, numpy, matplotlib.

## Running the Tests

```bash
python3 -m pytest tests/ -v
```

## Building the LaTeX Report

cd docs

## Key Concepts (CPS Verification)

| Concept | Implementation |
|---|---|
| Application | Software acoustic side-channel simulator |
| Hardware | Computer only, no microphone |
| Frequency signature | Custom frequency per key (KEY_FREQUENCIES) |
| Real-time task | Frequency -> key processing |
| WCET | Maximum measured processing time |
| Deadline | 50 ms (DEADLINE_MS) |
| Tolerance | 8 Hz (TOLERANCE) |
| Invariant | Unique/valid frequency mapping |
| Liveness | System continues accepting inputs |
| Termination | Finite sequence finishes |
| Ranking function | V = \|F_detected - F_expected\| |
| Safety | Invalid/ambiguous -> "UNKNOWN" |
| Outcome | Reconstructed keystroke sequence |

## Coding Conventions

- Python 3, standard library + numpy/matplotlib.
- Docstrings on all public functions.
- UPPER_CASE constants for configuration.
- Functions are self-contained and testable.
- No comments in code beyond section markers and function docstrings
  unless required.

## Notes for AI Agents

- Run tests after any change: `python3 -m pytest tests/ -v`.
- The LaTeX report embeds PNG figures generated by
  `waveform_visualization.py`.
- Do NOT introduce audio/microphone capture features. Keep it a
  simulation using predefined frequencies.
